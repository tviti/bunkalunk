* Introduction

This file tracks tasks and issues for GISDB development. It is an
[[https://orgmode.org][org-mode]] file, edited primarily using [[https://www.gnu.org/software/emacs/][GNU Emacs]], but is also a plain
text file that can be edited with any text editor. Since it's a
plain-text file, the hope is that this will be easy for contributors
to edit, and if necessary, easy to migrate to another platform.

* Task tracking system overview

The task tracking system is minimal by design, to minimize maintenance
overhead, and more importantly to facilitate future migration to other
task tracking systems (e.g. GitHub issues). Headings are declared with
preceding =*= characters, with the number of asterisks indicating the
heading's level. A heading should be formatted with the necessary
number of preceding asterisks, followed by a single space character,
followed by a =TODO= state, then another space, and then the heading
text. After the heading, you should write a descriptive body that
describes the task.

The =TODO= states defined are:
- =TODO=: Incomplete
- =WAITING=: Something is holding this task up
- =DONE=: Task has been completed
- =CANCELLED=: Task has been canceled

State changes should be recorded with a logdrawer entry. The [[https://orgmode.org/manual/Tracking-TODO-state-changes.html][org-mode
manual page for tracking TODO state transitions]] describes how these
should be formatted. If you are using Emacs to edit this file, the
formatting will be applied automatically (provided you use ~M-x
org-todo~ or ~C-c C-t~ to carry out the state transition). If you are
using some other text editor, the following two example tasks show the
format you should follow. You should try to include some prose in the
state-transition entry describing why the transition occurred, but
this is not required.

Two top-level headings are provided for organizing tasks: =Tasks= and
=Issues=.
- =Tasks=: Anything that needs to be done; intentionally kept
  general. Tasks can be features, maintenance items, or even vague
  ideas about how the system could be changed in the future
- =Issues=: Genuine problems with the system (i.e. bugs and defects) 

Tasks should also include a timestamp indicating their creation date,
following [[https://orgmode.org/manual/Timestamps.html][org-modes inactive-timestamp format]]. A blank line should
follow the timestamp.
